# 🪼 Jellyfish Finger

> 举起手，一群小水母就游过来找你的指尖啦～

摄像头看着你的手，食指指到哪儿，水母就游到哪儿。
不用装任何东西，打开网页就能玩。

### 👉 [点这里开始玩](https://jfojellyfish-glitch.github.io/jellyfish_finger/)

第一次进去点「开启摄像头」，浏览器问你要不要允许，选**允许**，然后举起一只手就行。

> 🔒 放心，摄像头画面只在你自己的设备上处理，**不上传、不保存**，谁也看不到。

---

## 怎么玩

| 你做什么 | 水母会怎样 |
|---|---|
| 🖐️ 移动食指 | 水母跟过来，围着你的指尖转圈圈 |
| ✨ 靠近水母 | 它们亮起来，触须散开，叮一声 |
| 💨 快速划一下 | 掀起水波，把水母推开，冒出气泡 |
| 🤏 捏住拇指和食指 | 水母收拢成一颗颗发光小水滴 |
| 👐 再张开手指 | 放出一只新的小水母（最多 12 只） |
| ✋ 摊开手掌停住 | 水母排成一圈，绕着你的手心慢慢转 |
| 🙌 两只手一起举 | 一手一群，中间拉出一道流动的水流 |
| 📸 右下角快门（或按 `R`） | 录 10 秒小视频，能存、能发、还能存成 GIF |

右上角还有一排小开关可以玩：换背景、开美颜、切水母样式、水波强弱、声音开关。

---

## 一点小提示

- **手机也能玩** 🍓 把网址发到微信或备忘录，用手机浏览器打开，同样点允许摄像头就行
- **第一次进去要等几秒** 它在偷偷加载识别模型，不是卡住了，稍等一下
- **举手要在画面里** 让手完整出现在摄像头前，光线别太暗，它才看得清你的手指
- **不想开摄像头？** 点「先用鼠标试试」，用鼠标也能逗水母玩

## 🫧

摄像头识别你的手 → 算出指尖位置 → 画面和声音全是浏览器现场生成的。
没有服务器、没有账号、没有广告，就是一个纯粹拿来玩的小东西。
